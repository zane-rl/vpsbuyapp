# 需求分析

## 1. 业务背景

为客户采购 VPS 服务器并在其上搭建 VPN 服务。当前缺少集中记录与展示工具，导致：

- 多台 VPS 的到期时间分散，难以及时续费，存在服务中断风险；
- 采购成本与客户收款没有统一台账，利润核算困难；
- 客户无法自助查看自己的服务器有效期与可用节点，沟通成本高。

本系统用于解决以上问题：**统一记录 VPS 资产与财务、管理 VPN 节点，并通过独立客户账号提供只读业务门户与终端用户分配能力**。

## 2. 角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 管理员（运营者） | 采购 VPS、搭建 VPN、维护数据的人 | 登录后台，增删改 VPS / 续费 / 节点，查看财务 |
| 客户 | VPS 与资金往来的结算单位 | 使用管理员分配的独立账号登录，只读查看自己的完整业务资料；维护终端用户和节点分配 |
| 终端用户 | 客户记录的 VPN 实际使用人员 | 不能登录系统，只能被分配节点 |

## 3. 功能需求

### 3.1 VPS 资产管理
- 记录服务器**提供商**（如 Vultr / DigitalOcean / 搬瓦工）。
- 记录**基本配置**：CPU、内存、硬盘、带宽/流量、地区、IP 地址、操作系统。
- 记录**购买时间**与**到期时间**。
- 记录**运行状态**（运行中 / 永久下线）与下线时间。
- 支持从详情页永久下线；下线不可恢复，保留历史资产与财务，但停止余额消耗估算、续费与到期提醒。
- 支持新增、编辑、删除。
- **一键复制**：基于已有 VPS 复制配置快速新建，便于录入同一提供商的多台同配置 VPS（复制后名称加"-副本"、清空 IP，供修改后保存）。

### 3.1b 计费类型（固定期限 / 自动续费）
- **固定期限（term）**：一次性按 **月 / 季度 / 年** 购买，有完整到期时间，显示剩余天数，到期续费延长到期时间。新建/编辑时选择**购买周期**，到期时间按购买时间自动推算（仍可手动调整）。
- **自动续费（auto）**：无固定到期，按小时/月/季度/年根据账户余额自动扣费续费；展示蓝色「自动续费中」徽章；记录续费周期 + **周期费用(USD)**（用于估算消耗）。
- 自动续费**不再按单台维护余额**，改为**客户级共享充值余额**（见 3.4b）：详情页只读展示「所属客户共享余额（估算）」与「预估到期」，充值在客户页面统一进行。
- **VPS 必须关联客户**（新建/编辑时「所属客户」为必填）。

### 3.2 续费（固定期限）
- 对固定期限 VPS 执行续费操作，填写续费后到期时间。
- 续费后系统将该 VPS 的到期时间更新为最新值。
- 保留每一次续费的历史记录（续费前后到期时间、金额、备注）。
- 校验：续费后到期时间必须晚于当前到期时间。
- 支持**删除续费记录**（仅删除历史记录，不改动 VPS 当前到期时间；如需调整到期时间在编辑 VPS 中修改）。

### 3.3 提供商与客户（单独维护）
- **提供商**：单独维护提供商列表（仅名称），新增/编辑 VPS 时从中选择，而非手填。
- **客户**：单独维护客户（名称 + 备注）；每台 VPS 归属一个客户。
- 删除提供商/客户时，被引用的 VPS 仅将对应字段置空，不删除 VPS。

### 3.4 财务记录与按客户结算
每台 VPS / 每次续费记录**两笔成本**（运营者支出）：
- **采购成本（USD）**：VPS 的美元标价成本。
- **实际付款（CNY）**：购买时实际花掉的人民币（含汇率/手续费差异）。
- **实际付款截图**：可上传付款截图（图片，存服务器本地），VPS 与每次续费各自一张；管理员可看全部，客户登录后只能看自己记录关联的凭证。

**客户收款不在 VPS 页面维护**，而是独立的**收款台账**（归属客户）：一笔付款可对应多台 VPS（统一付款），后续续费等可多次收款。

汇总（全局 / 按客户两个层级）：
- 总成本（USD）、总实付成本（CNY）、总收款（CNY）；
- **差额（CNY）= 总收款 − 总实付成本**（正=盈余/客户多付，负=欠款）。
- **概览页提供「按客户统计」表**：每个客户的 VPS 数、总成本$、总实付¥、收款¥、差额¥。

### 3.4b 客户充值（自动续费共享余额）
- 给客户的自动续费 VPS **提前充值**（预充值）：在客户管理页记录**充值美元(USD) + 实付人民币(CNY) + 充值后实际余额(USD) + 日期 + 截图 + 备注**。
- 名下所有运行中的自动续费 VPS **共享该客户余额**。下线服务器只计算至 `stoppedAt` 的历史消耗，之后不再扣减；下线不会退回此前消耗。当前日均消耗和预计耗尽日只包含运行中的 auto VPS。
- **预估到期/耗尽时间**：`余额 ÷ 日均消耗`，得出「预计可用至 YYYY-MM-DD（约 N 天）」；同客户多台 auto VPS 共享同一耗尽日。周期天数：小时=1/24、月=30、季度=90、年=365（估算）。无周期单价/无充值/已耗尽时给出对应文案。
- **充值美元计入总成本、实付人民币计入总实付成本/差额**（与续费一致）。

### 3.5 VPN 节点管理
- 每台 VPS 下可记录多个 VPN 节点，节点**归属对应 VPS**。
- 节点信息：名称、协议（Shadowsocks / V2Ray / Trojan / WireGuard 等）、地址/域名、端口、配置（加密方式/密码等）、**订阅链接**、是否启用。
- 订阅链接在后台维护，客户门户也展示（带复制按钮，方便客户导入）。
- 支持新增、编辑、删除。

### 3.6 客户门户（账号登录）
管理员为每个客户分配一个全局唯一用户名和初始密码。客户首次登录必须修改密码；管理员可启停账号、修改用户名或重置密码，以上操作会使旧会话失效。不存在自助注册和找回密码。

**`/customer`** 仅展示登录账号所属客户的数据；旧 `/view/<客户ID>` 不再渲染数据，统一跳转客户登录。
- 每台 VPS 展示：名称、提供商、配置、购买/到期时间、**剩余时间**（彩色徽章，仅一个）、**购买成本（USD）**、**实际付款（CNY，含该机全部续费）**、已启用 VPN 节点。
- 顶部合计：**总购买成本（USD）**、**总实际付款（CNY）**（含续费与充值）、**总收款（CNY）**、**差额**；含自动续费 VPS 时展示**当前充值余额（USD）**。
- **付款记录 / 收款记录左右并排**，方便客户逐笔对账：
  - 左「付款记录」= 该客户的整体购买服务器开销台账，汇总**每台服务器的购买付款 + 各次续费付款 + 余额充值**三类，每行带类型徽章、成本 USD、实付 CNY 与**付款截图**，表尾合计与「总实际付款」同口径。
  - 右「收款记录」= 客户已支付给我方的每一笔（时间、金额、备注、**收款截图**），表尾合计与「总收款」一致，并给出「收款 − 实付 = 差额」一行。
- 客户只能修改自己的登录密码、终端用户和节点分配；服务器、节点配置、财务和通知配置均只读。

### 3.6a 终端用户与 VPN 节点分配
- 终端用户是姓名、联系方式、备注和状态组成的人员档案，不是系统登录账号。
- 管理员和客户均可新增、编辑、停用/启用终端用户；停用不删除现有分配。
- 一个终端用户可分配多个节点，同一节点也可分配给多人；只保存当前关系与分配时间。
- 只有运行中 VPS 的启用节点可分配给启用用户。服务器下线、节点禁用或用户停用后保留现有关系并标记不可用，仍可解除。
- 存在节点分配时禁止把 VPS 改派给其他客户，必须先解除全部分配。

### 3.6b 到期主动提醒（Telegram）
- 运行中服务器剩余有效期不足 N 天（默认 **5 天**）时自动提醒；下线服务器不检查。
- 两类计费都覆盖：`term` 按到期日剩余天数判断；`auto` 按共享余额的**预估耗尽日**判断。
- **收件人按客户单独配置**：客户收件人收到客户门户链接；全局收件人通常是管理员，收到对应后台客户详情链接。
- 同一客户同一天只推送一次，避免定时任务重复触发时刷屏。
- 每个客户详情页有「**发送测试推送**」按钮，可随时给该客户的收件人发一条测试消息（带「测试消息」前缀），用于验证配置是否配好，不影响正式推送。

### 3.7 管理后台（密码保护）
- 单管理员密码登录，顶部导航：VPS / 客户 / 提供商 / 设置。
- VPS 列表（客户、提供商、IP、付费类型、创建时间、到期时间、状态、金额，斑马纹）+ 全局财务汇总卡片 + 按客户统计表。
- 提供商管理、客户管理（含每客户结算、收款台账与**到期提醒收件人**）、VPS 增删改、续费、节点管理。
- 设置页：Telegram 推送开关/Token/提前天数/站点地址、全局收件人、各客户收件人概览、定时任务配置示例、推送记录。
- 概览页右上角有「到期推送已开启/未开启」入口（绿点=已配好），未配好时正文显示引导条，指向设置页。窄屏没有顶部导航时，这里是进设置页的入口。

## 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 鉴权 | 管理员用环境变量密码；客户用数据库中的 scrypt 密码哈希与独立签名 Cookie，会话按客户隔离 |
| 部署 | 可部署到 Ubuntu 24.04，**监听端口通过环境变量 `PORT` 配置** |
| 数据 | 使用 SQLite 单文件存储，便于备份迁移 |
| 易用性 | 中文界面；到期状态用颜色直观区分 |
| 安全 | 客户页面、接口与付款凭证均按会话客户归属校验；Cookie 为 httpOnly；推送端点用 `CRON_SECRET` 鉴权 |

- VPS 提供商 API 对接、自动开通/续费。
